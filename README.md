# Cheruiyot Kevin | Portfolio

A modern, responsive portfolio website built with **React**, **Vite**, and **Tailwind CSS**. This project showcases my work as a Data Analyst and Software Developer.

## 🚀 Features
- **Responsive Design:** Optimized for mobile, tablet, and desktop.
- **Project Showcase:** Highlights data analytics and software engineering projects.
- **Dynamic Skill Grid:** Categorized technical expertise.
- **Resume Integration:** One-click PDF download functionality.

## 🛠️ Tech Stack
- **Frontend:** React.js, TypeScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Icons:** Lucide React
